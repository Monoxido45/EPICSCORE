**Running Time vs. Sample Size**: This experiment evaluates the computational cost of the EPICSCORE method across increasing sample sizes (\(n\)) using three Bayesian predictive models: Mixture Density Networks (MDN), Bayesian Additive Regression Trees (BART), and Variational Gaussian Processes (GP). The task involves a synthetic regression problem with 30 input features and one response variable. For each sample size (\(n = 1000, 2000, 5000, 10000, 20000, 50000\)), we generate the same dataset and apply a consistent 50/50 train/calibration split across models. Each experiment is repeated 10 times, and we report the average runtime and standard deviation.

The MDN configuration includes two hidden layers (64–64 units), ReLU activations, 50% dropout, 2000 training epochs, a learning rate of 0.001, and batch size dynamically scaled to the sample size (ranging from 35 to 450). Inputs are standardized, and the response is normalized. BART is configured with 50 trees, normal heteroscedastic errors, 500 posterior samples, and parallelization using 6 CPU cores. The GP model is trained via a variational approximation, with the number of inducing points dynamically adjusted from 15 to 150 based on \(n\), a variational learning rate of 0.1, a hyperparameter learning rate of 0.01, and identical batch size and early stopping parameters to the MDN.

The results show that all methods perform similarly at moderate sample sizes (e.g., \(n = 10000\)), but for larger datasets, MDN achieves markedly better scalability and significantly faster runtimes. These findings highlight MDN’s practicality for high-sample regimes, with much of the runtime behavior attributed to its efficient use of early stopping.
