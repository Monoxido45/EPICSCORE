**Running time x n**: In this experiment, a regression task is performed using 30 features and one response variable with varying sample sizes \( n \). For each sample size, the execution time of the EPISCORE method is measured using BART, MDN, and GP models. Each configuration is repeated 10 times with different data splittings, and the average execution time and standard deviation are computed for each Bayesian model. The sample sizes considered are 1000, 2000, 5000, 10000, 20000, and 50000. The datasets used across the three methods are the same, and the data splitting consists of training and calibration sets, both with the same number of samples \( n \). EPISCORE with the Mixture Density Network (MDN) model uses two hidden layers (64–64 units), a dropout rate of 50%, 2000 training epochs, a learning rate of 0.001, and a dynamic batch size (ranging from 35 to 450) based on sample size. The response is normalized, and the input data is standardized. For BART (Bayesian Additive Regression Trees), the configuration includes 50 trees, normal and heteroscedastic error distributions, 500 posterior samples, and parallel processing with 6 cores. The Gaussian Process (GP) model is trained using an approximate variational approach with a dynamic number of inducing points (ranging from 15 to 150), 2000 epochs, a variational learning rate of 0.1, and a hyperparameter learning rate of 0.01. The batch size and early stopping patience (set to 50) are the same as those used for the MDN model. All three methods show approximately equal running times at \( n = 10000 \), but for larger sample sizes, MDN clearly dominates with the lowest runtime. This experiment reveals that MDN is extremely fast at computing predictive regions, and its pattern of runtime increase or decrease with larger sample sizes is primarily due to the use of early stopping.
